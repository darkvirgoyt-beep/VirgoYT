🚀 About FogOS

FogOS is a performance-oriented custom Android kernel designed for users who want improved:

- Gaming responsiveness
- Touch performance
- CPU scheduling
- Memory management
- Network behavior
- System smoothness

Built with gaming workloads in mind, including:

- 🎮 BGMI
